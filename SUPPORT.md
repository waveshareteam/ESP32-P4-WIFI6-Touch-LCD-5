# Support

Use the [official product documentation](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-5)
for setup, wiring, flashing, and product instructions. For a reproducible
repository problem, open a
[GitHub issue](https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-5/issues/new/choose).

## Include in a technical report

- board/product name and hardware revision, if known;
- affected example path;
- exact ESP-IDF version;
- steps to reproduce;
- expected and actual behavior;
- relevant build or serial log;
- whether the test used source built by Actions or the factory image;
- any hardware, BSP, pin, component-range, or firmware changes.

## Protect private information

Before posting publicly, remove credentials, tokens, account identifiers,
network secrets, personal data, actual device identifiers, and machine-specific
paths. Reduce logs to the section needed to reproduce the problem.

This repository does not currently publish a verified private vulnerability
reporting channel. Do not post credentials or unpatched vulnerability details
in a public issue. Use
[official Waveshare support](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-5/Technical-Support)
to request an appropriate private contact before sharing sensitive details.

## Evidence boundaries

Actions build results prove compile compatibility for the checked commit. They
do not prove runtime hardware behavior, P4/C6 interoperability, or that the
factory image was rebuilt. See [hardware validation](docs/HARDWARE.md) and the
[hosted Wi-Fi contract](docs/P4_C6_HOSTED_WIFI.md).
