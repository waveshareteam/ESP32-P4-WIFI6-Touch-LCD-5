# ESP32-P4 与 ESP32-C6 Hosted Wi-Fi 兼容性

[Wi-Fi Station 示例](../examples/esp-idf/04_wifistation/README_ZH.md)运行在
ESP32-P4 上，并使用板载 ESP32-C6 作为无线协处理器。主机组件版本线与 C6 从机固件
必须保持互操作。

## 主机依赖范围

| ESP-IDF 版本线 | esp_wifi_remote | esp_hosted |
| --- | --- | --- |
| 低于 6.0，包括 v5.5.5 | 0.14.* | 1.4.* |
| 6.0 及以上，包括 v6.0.2 | >=1.6,<2.0 | >=2.12,<3.0 |

这些范围写在示例 manifest 中，并由必需的 Actions 矩阵验证能够编译。编译成功不代表
它能够与每一种 C6 从机镜像通信。

## 固件边界

本仓库目前尚未包含板载 C6 从机固件的源码或构建说明，后续可能补充。仓库中的出厂镜像
属于独立的不可变交付产物，不由示例工作流重新构建。

修改任一主机依赖范围时：

1. 确认开发板配套的精确 C6 从机固件；
2. 运行两条必需的 ESP-IDF 主机构建；
3. 在硬件上验证连接、IP 流量、重连和重启行为；
4. 只有取得匹配的主机/从机证据后才更新本表。

原理图中可以看到 P4 到 C6 的物理传输信号，但该示例没有维护源码级传输引脚表。不要
从其他开发板推断本产品映射。

## 重新评估条件

当配套的新旧 C6 从机镜像、源码或构建说明可用后，应执行端到端验证，并用明确的
主机/从机矩阵替代宽泛的兼容性假设。
